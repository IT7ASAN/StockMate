# رفيق المخزون

تطبيق ويب تقدّمي عربي لإدارة المنتجات والكميات والرفوف. تُحفظ البيانات والصور محلياً في المتصفح باستخدام IndexedDB، ولا توجد مزامنة تلقائية بين الأجهزة.

## المزايا

- إدارة المنتجات وكميات البراد والمخزن والصلاحية والباركود والصور.
- تسجيل نقل المخزون أو الإضافة والسحب أو الجرد من نموذج مبسط، مع معاينة الرصيد قبل الحفظ وسجل للحركات.
- قسمان ثابتان للرفين الأول والثاني، ويمكن إضافة عدة أقسام داخل كل رف. لكل قسم اسم ونوع (رف مفتوح، درج، صندوق، مبرد) وشكل مرئي؛ ولكل رف صورة واسم وموقع. اختر القسم عند إضافة المنتج، وانقل منتجات القسم قبل حذفه.
- قائمة تعبئة مرتبة حسب الرف والقسم، تقترح أقل كمية لازمة ضمن رصيد المخزن وتسمح بتعديلها ونقلها لكل منتج منفرداً.
- سجل للحركات مع تصفية حسب النقل والإضافة والسحب والجرد، وإظهار مكان المنتج ورصيده بعد الحركة.
- تضاف ثلاثة منتجات تجريبية مرة واحدة لتسهيل تجربة الصفحات والحركات، مع الحفاظ على المنتجات الموجودة. يمكن تمييزها بوسم «بيانات تجريبية».
- قراءة الباركود بالكاميرا عبر `BarcodeDetector` عند توفره، أو عبر قارئ ZXing البديل. يتطلب قارئ ZXing اتصالاً بالإنترنت عند أول استخدام؛ ويُخزّنه التطبيق مؤقتاً بعد تحميله. يمكن أيضاً مسح صورة باركود أو إدخال الرقم يدوياً.
- نسخ احتياطي JSON يتضمن المنتجات والحركات والرفين وأقسامهما وصورهما، واستيراد ملفات النسخ السابقة. عند استيراد نسخة فيها رفوف إضافية، تُجمع منتجاتها ضمن الرف الثاني.
- تثبيت كتطبيق PWA والعمل دون اتصال بعد تحميل ملفات التطبيق. قد يحتاج قارئ ZXing إلى اتصال في أول استخدام.

## التشغيل

1. ارفع محتويات المجلد إلى GitHub Pages أو أي استضافة HTTPS.
2. افتح الموقع في المتصفح، واسمح للكاميرا عند بدء المسح.
3. يمكن تثبيت التطبيق على الشاشة الرئيسية من قائمة المشاركة في Safari أو قائمة المتصفح.

يجب فتح التطبيق عبر HTTPS أو `localhost` لاستخدام الكاميرا وميزات PWA؛ فتح `index.html` مباشرة لا يكفي.

## البيانات والنسخ الاحتياطي

البيانات محلية على الجهاز والمتصفح الحاليين. صدّر نسخة JSON بانتظام قبل مسح بيانات المتصفح أو تغيير الجهاز. عند استيراد نسخة، تُستبدل البيانات الحالية بعد طلب التأكيد. يحافظ التطبيق على بيانات الرفين الحاليين وأقسامهما، ويحوّل أي رفوف إضافية قديمة إلى الرف الثاني حتى تبقى المنتجات مرتبطة بأحد القسمين.

لا تُستخدم إشعارات الخلفية المجدولة؛ يجري فحص التنبيهات عند فتح التطبيق. الصلاحية حقل واحد لكل منتج وليست نظام دفعات متعددة.

## الاختبار المقترح

بعد تجربة المنتجات التجريبية، يمكنك حذفها أو تعديلها ثم متابعة إدخال المنتجات الفعلية. راجع نسخة احتياطية قبل الاستخدام اليومي.
