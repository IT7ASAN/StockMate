# StockMate — النسخة الأولى

تطبيق ويب تقدمي (PWA) عربي لإدارة مخزون المشروبات محلياً على جهاز واحد.

## تشغيله
1. فك ضغط الملف.
2. ارفع محتويات المجلد إلى GitHub Pages أو أي استضافة تدعم HTTPS.
3. افتح رابط الموقع في Safari على iPhone.
4. من زر المشاركة اختر **إضافة إلى الشاشة الرئيسية**.

يمكن تشغيله محلياً للتجربة عبر خادم محلي، لكن فتح `index.html` مباشرة باستخدام `file://` لن يفعّل ميزات PWA.

## الميزات
- إضافة وتعديل وحذف المنتجات.
- بيانات المنتج: الاسم، العلامة، النكهة، الحجم، الباركود، الرف، الموقع، ثبات الموقع، الصلاحية.
- كميات منفصلة للبراد والمخزن.
- هدف تعبئة البراد وحد تنبيه المخزن.
- قائمة تعبئة محسوبة تلقائياً ومرتبة حسب الموقع.
- تسجيل حركات نقل وإضافة وسحب وجرد.
- وحدات القطعة والكرتون مع تحويل الكرتون إلى قطع.
- تنبيهات داخل التطبيق لانخفاض المخزون والصلاحية خلال 7 أيام.
- طلب إذن إشعارات المتصفح؛ التنبيه هنا يعمل عند فتح التطبيق وليس كجدولة مضمونة في الخلفية.
- تصدير واستيراد JSON.
- تخزين IndexedDB محلياً ودعم العمل دون اتصال بعد أول تحميل.

## حدود النسخة الأولى
- البيانات محفوظة على هذا الجهاز والمتصفح فقط؛ مسح بيانات Safari قد يحذفها.
- لا توجد مزامنة بين الأجهزة أو المستخدمين.
- لا يوجد مسح كاميرا للباركود بعد؛ حقل الباركود جاهز لإدخال الرقم أو استخدام قارئ خارجي.
- تاريخ الصلاحية الحالي حقل واحد لكل منتج؛ إذا كانت للمنتج دفعات متعددة بتواريخ مختلفة، يلزم تطوير نظام دفعات (Batches) في النسخة التالية.
- لا تعتمد على إشعارات الويب وحدها لإدارة صلاحيات المنتجات أو نفادها؛ افتح التطبيق خلال جولات العمل وراجع التنبيهات.

## نصيحة مهمة
قبل إدخال المنتجات المئة، جرّب النظام على 5 إلى 10 منتجات لمدة يومين. تحقق من دقة الكميات وطريقة النقل، ثم أدخل بقية المنتجات.
